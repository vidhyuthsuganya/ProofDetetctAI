# ProofDetect AI 2.0

A free Streamlit mathematics tutor and proof-checking learning prototype.

## Run locally
1. Install Python.
2. Open a terminal in this folder.
3. Run `python -m pip install -r requirements.txt`.
4. Run `python -m streamlit run app.py`.

## Current supported features
- Linear and polynomial equations using SymPy.
- Implicit multiplication such as `2x` and `3(x+2)`.
- Arithmetic, simplify, expand and factorise.
- Selected geometry angle questions and Pythagoras.
- A cautious proof-step pattern checker.

## Limitations
This is not a universal natural-language maths AI. Word problems, diagrams, advanced topics and complete proof verification are not yet supported. Proof checks may return NEEDS REVIEW rather than guessing.
